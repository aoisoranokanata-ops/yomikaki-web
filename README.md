# yomikaki web — 読書・執筆 総合管理（ブラウザ版）

[yomikaki（デスクトップ版）](../yomikaki/README.md) のブラウザ／スマホ版。
**単一HTMLファイル**で動作し、データはブラウザ内（IndexedDB）に保存されます。

## 起動方法

- `index.html` をダブルクリック（そのまま動きます）
- または開発サーバー: プロジェクトルートで `python -m http.server 8648 --directory yomikaki-web`

## PWA（スマホでの利用）

サーバー経由（http/https）で開くと Service Worker が登録され、
**オフラインでも起動**します。ブラウザの「ホーム画面に追加」でアプリのように使えます。

## exe版とのデータ連携

**JSONバックアップの形式がデスクトップ版と完全互換**です。

- exe版でエクスポート → Web版の「📥 インポート」で読み込み
- Web版でエクスポート → exe版の「ファイル → JSONから復元」で読み込み

インポートは **上書き** と **マージ**（現在のデータを残して追加。IDは自動で振り直し、
関連データの紐づけも保たれます）を選べます。

## 機能

読者モード（作品リスト／読書カレンダー／引用・語彙帳）と
作者モード（作品情報・執筆原稿・プロット・相関図・登場人物・世界観・時系列・
参考資料・作品分析）を搭載。挿入ツールバー（F1〜F6）、ルビ・傍点、
縦書きプレビュー、章／全体プレビュー、コピー3種、行間調整・字下げ、
Claude連携（プロンプト生成＋コピー）に対応しています。

## exe版との違い

| 項目 | exe版 | Web版 |
|---|---|---|
| URL自動取得（なろうAPI/カクヨム） | ✅ | ❌ ブラウザのCORS制約で不可 |
| 登場人物の画像添付 | ✅ | ❌ 未実装（データは保持され、exe版に戻せば表示可） |
| 縦書きプレビュー | 簡易描画 | CSS `writing-mode` による本格縦書き |
| データ保存先 | `library.db`（SQLite） | ブラウザ内 IndexedDB |

Web版はブラウザのデータを消すと記録も消えるため、**定期的なJSONエクスポート**を推奨します。

## ファイル構成

- `index.html` — アプリ本体（単一ファイル）
- `manifest.webmanifest` / `sw.js` / `icon-192.png` / `icon-512.png` — PWA用
